# DeepSeek Harness → C# / .NET 10 移植计划

[English](README.md) | 中文

本文件夹存放把仓库从 TypeScript monorepo 移植为 **C# / .NET 10** 代码库的计划：CLI（命令行界面）采用 **TUI**，Web UI 采用 **Blazor**。

## 已锁定的决策

以下决策在计划撰写前已与需求方确认：

- **Web UI 模型：**Blazor Server / Blazor Web App，使用服务器交互。
- **范围：**完整的 .NET 移植；Python SDK 被重写（不再保留 Python），文档网站并入 Blazor 应用，原生 `landlock-run` 沙箱保持原生（P/Invoke 或 sidecar）。
- **排序：**先做概念验证 spike，再进行增量式 strangler 迁移，只有在达到对等之后才退役 TypeScript 代码树。
